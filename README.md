# Introduction to GPUs

Teaching materials for a one-hour, hands-on GPU introduction session using Google Colab.

## Start Here

Open [`introduction-to-gpu/README.md`](introduction-to-gpu/README.md) for the course-material index.

The module includes:

- Topic-by-topic instructor notes
- Beginner-friendly GPU explanations and diagrams
- Student questions and teaching prompts
- Google Colab setup and troubleshooting
- NumPy CPU, PyTorch CPU, and PyTorch GPU benchmarks
- A production bridge from Colab to AWS Lambda plus AWS Batch GPU jobs
